# CSImage 用户手册

## 安装与默认应用

运行安装包时，安装目录默认预填为 `D:\CSImage`，这只是建议值。首次安装、覆盖安装和升级安装都会显示“选择目标位置”页面，可以直接编辑路径，也可以点击“浏览”在图形化窗口中按需展开本地磁盘和文件夹；该窗口不会扫描网络磁盘。随后选择是否创建桌面快捷方式和图片右键菜单。安装完成后打开 Windows“默认应用”，选择“CSImage”，再确认需要关联的扩展名。程序不会静默替换默认应用。详细步骤见同目录的 `DEFAULT_APP_HELP.md`。

覆盖升级时，安装器会请求正在运行的程序保存并退出；存在未保存编辑时可以保存、放弃或取消升级。卸载默认询问是否保留设置、最近记录、恢复会话、日志和更新缓存。静默卸载默认保留，只有维护人员显式传入 `/CLEARUSERDATA` 才会清除。

## 查看图片

可直接打开常见图片、PSD、PSDT 和 PDF。PSD/PSDT 使用专用 Photoshop 文档解析器显示合成预览，不修改独立图层；PDF 会显示总页数，使用鼠标滚轮或滚动条纵向连续浏览整份文档，当前页会随视口自动更新。按住 `Ctrl` 再滚动鼠标滚轮可缩放 PDF。PSD、PSDT 和 PDF 都按只读源处理：进入快速编辑后，完成按钮会显示为“导出副本”，可把当前合成图或 PDF 当前页保存为 PNG、JPEG 或 WebP，源文件不会被覆盖。

- `Ctrl+O` 打开一张或多张图片，也可拖入窗口或双击已关联图片。
- 左右方向键或 `PageUp/PageDown` 切换图片，`Home/End` 跳到首尾。
- `Ctrl+0` 适应窗口，`Ctrl+1` 实际大小，`Ctrl++/Ctrl+-` 缩放。
- `F11` 全屏，`Ctrl+F11` 沉浸模式，`F5` 启停幻灯片。
- `Alt+Enter` 查看格式、尺寸、文件大小、日期和基础 EXIF。

程序为单实例；连续双击图片会把路径转发到现有窗口。后台解码和相邻预取不会阻塞当前窗口，损坏文件会显示可恢复提示并允许继续切图。

## 非破坏编辑

展开“编辑工具”后可旋转、翻转、裁剪、调整尺寸和色彩。进入裁剪后，在图片上拖出选区，再点击画布下方的“应用裁剪”或按 `Enter`；点击“取消”或按 `Esc` 只取消本次框选，不删除已经应用的裁剪。纯图标按钮悬停后会显示中文功能提示。历史面板支持 `Ctrl+Z/Ctrl+Y`、跳转任意节点和编辑前后比较。原图在导出前不被改写。

`.lieproj` 项目保存版本化命令历史并外部引用原图。移动项目时应同时保留原图；源文件变化时程序会要求重新定位或只读打开。异常退出后，下次启动可以恢复未完成会话或安全放弃。

## 标注和隐私工具

可添加文字、箭头、直线、矩形、椭圆、画笔和序号，也可使用马赛克、模糊与遮挡。对象在应用前以及保存项目后仍可选择、移动、缩放并修改颜色、描边和透明度。

在看图界面点击顶部的编辑按钮，会打开截图式快速编辑栏。工具栏将“选择”与矩形、箭头、直线、椭圆、画笔、文字、序号、马赛克、模糊和遮挡等绘制工具明确分开：绘制工具始终创建新对象，因此可以在已有标注内部或上方继续绘制；对象画完后自动回到“选择”状态。选择状态下点击已有标注可重新选中，拖动对象可修改位置，拖动白色控制点可调整矩形类区域的尺寸。直线和箭头具有起点、曲线上的中间弯曲点、终点三个控制点：初始保持直线，拖动线上中间点即可直接改变曲线，箭头方向会跟随曲线末端切线。选中对象时工具栏会同步其颜色、线宽或字号；未选中对象时属性控件会禁用，避免误改下一次绘制参数。`Delete` 删除对象，`Esc` 依次取消文字输入、取消当前选择、退出编辑；`Ctrl+Z` 可逐步撤销创建、移动、缩放、改属性、改文字与删除。序号会按当前图片中的标注自动递增；选择文字时“大小”控件会切换为独立的 `8～96 px`“字号”，默认 `20 px`，不会与画笔线宽混用。这里的字号表示当前画面上看到的大小，小图片即使被放大显示也不会把输入文字同步放大数倍。选择文字后在图片上点击位置，直接在原位输入，按 `Enter` 确认、按 `Esc` 取消；在选择状态下双击已有文字可以继续修改，切换其他工具、仅复制或替换原图前会先提交非空文字。完成后可以取消全部修改、仅复制结果，或者在二次确认后替换原文件。

“仅复制”不会修改原图，适合聊天、文档和工单中的临时标注；拖动马赛克或模糊区域时，画布会实时显示真实像素效果，松开后继续保留预览，并在复制或替换时写入最终结果。处理敏感信息时仍建议在发送前放大检查边缘是否完整覆盖。

## 保存与导出

`Ctrl+S` 保存，`Ctrl+E` 快速导出。覆盖原文件前可启用 `.bak` 备份；写入采用临时文件和原子替换，失败不会破坏原文件。动画 GIF/APNG/WebP 不会在没有提示时保存成单帧。

导出时可选择社交媒体、头像、邮件、原质量或自定义预设。格式能支持时可保留 EXIF、ICC、DPI、XMP 和透明通道；转换到不支持透明的格式前会要求确认。

## 批量处理

选择文件或文件夹后设置格式、尺寸、质量、水印、元数据清理和重命名模板。任务队列限制并发与内存；只读、损坏、超大或同名文件只会使自身失败。任务可取消、恢复、重试失败项、导出日志或再次运行。

## 更新、回滚和隐私

设置页可选稳定版或测试版。程序只在点击“立即检查更新”后联网；清单签名、安装包大小、SHA-256 与 Windows 发布者签名必须全部通过。验证失败不会安装任何内容。上一份已验证安装包可用于回滚，并会在回滚前再次验证。

图片始终在本机处理。诊断 ZIP 由用户主动导出，不含图片，并遮蔽路径、邮箱、IP 和密钥样式内容。匿名崩溃上报默认关闭；即使在设置中同意，每份报告发送前仍需再次确认。

## 故障处理

- 无法拖放：确认使用 0.7.0 之后版本，并尝试从“文件→打开”验证文件本身。
- 图片无法打开：查看提示属于损坏、权限不足、尺寸过大还是缺少可选 HEIF 插件。
- 更新失败：保留错误提示并导出诊断 ZIP；不要绕过签名或哈希检查。
- 程序异常退出：重启后选择恢复；如问题重复，打开“信息→导出问题报告”。
- 需要彻底重置：先备份项目，再从“已安装的应用”卸载并选择清除本地数据。

`F1` 可查看完整快捷键。反馈问题时请提供 Windows 版本、DPI、安装/便携版、复现步骤和脱敏诊断 ZIP，不要上传含隐私的原始图片。
