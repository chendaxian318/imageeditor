# v0.8.0 Beta 发布说明

本版本建立公开测试和可持续发布基础：稳定/Beta 双更新通道、签名清单与安装包多重校验、上一验证版本回滚、本地崩溃恢复记录、脱敏诊断包、设置迁移、可选择保留数据的卸载流程、SHA-256 与 CycloneDX SBOM。

更新检查和诊断导出均由用户主动触发。匿名崩溃上报默认关闭；即使用户在设置中同意，每份报告发送前也必须再次确认。图片不会被加入诊断报告或后台上传。

公开分发前必须完成受信 Authenticode 代码签名、20～50 人封闭测试以及 P0/P1 清零。详见 `BETA_PLAN.md` 和 `KNOWN_ISSUES.md`。
