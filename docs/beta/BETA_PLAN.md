# 封闭 Beta 计划

目标招募 20～50 名 Windows 10/11 x64 用户，覆盖普通办公、内容创作、大图/批处理、高 DPI/多显示器和非管理员账户。分三波放量：5 人冒烟 2 天、15～25 人核心回归 5 天、20～50 人候选版 7 天；上一波无未控制 P0 才能进入下一波。

每名测试者须完成安装、从 v0.7 升级、打开/拖放/切换图片、保存编辑项目、导出、批处理、更新失败模拟、回滚和卸载保留/清除数据，并提交环境、复现步骤、期望/实际结果和诊断 ZIP。不得要求上传原始私人图片。

## 缺陷门禁

| 级别 | 响应 | 负责人要求 | 关闭标准 |
|---|---:|---|---|
| P0 数据丢失/安全绕过/无法启动 | 4 小时 | 创建时必须指派 | 修复、回归、异常注入和至少 2 名复测者通过 |
| P1 核心流程阻断/高频崩溃 | 1 工作日 | 当日指派 | 修复、自动化回归和原报告者复测通过 |
| P2 一般体验问题 | 3 工作日 | 迭代内指派 | 有复现、验收标准并排入里程碑 |

`P0_P1_REGISTER.md` 是发布门禁台账；没有负责人、关闭标准或验证证据的 P0/P1 一律视为未关闭。Beta 负责人每天汇总新增、重开和关闭数量，并在每波结束时记录继续、暂停或回滚决定。
