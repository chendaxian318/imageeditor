# 轻量图片编辑器 2.0.0 候选发布说明

> 当前状态：候选文档。只有 `V2_RELEASE_GATES.json` 与最终构建生成的
> `RELEASE_GATE_STATUS.json` 均通过后，才能作为公开稳定版发布。

## 主要变化

- 纯中文 Material You 四模式工作台：看图、转图、改图和生图职责分离，资源与修订可在模式间安全交接。
- “全部功能”面板可通过底部入口或 Ctrl+K 搜索 135 项台账能力，并按当前模式、全局或四个模块筛选后执行原有真实回调。
- 看图模式具备文件夹浏览、连续缩放、动画控制、不同文件比较和发布级性能门禁。
- 转图模式具备真实队列、裁切/尺寸/格式配方、检查点恢复、失败重试、动画与透明策略及批量保真门禁。
- 改图模式保留原有调色、标注和非破坏历史，并提供本地高清、支持受控贴边/缓慢渐变及原 Alpha 保留的背景去除、边缘画笔、纯色/自定义图片背景替换、带多主体候选切换、像素蒙版预览、加入/移出画笔精修和蒙版隔离修复的规则/渐变背景物体擦除，以及具备横排至竖排普通印刷体区域建议、竖排方向切换、框内识别、相似字体推荐和手工校正排版的改文字基线。
- 生图模式具备候选工作区、持久收藏与筛选、安全移除、最多四张参考图、固定种子、风格、变体、来源记录和三模式交接；移除工作区候选不会破坏受管修订或任务追溯。
- 统一任务托盘集中管理转图、智能改图和生图任务，支持取消、显式重试和重启恢复。
- SQLite 素材库、修订树、异步任务、逐次上传/费用授权和失败关闭发布门禁统一管理 AI 生命周期。

## 当前候选限制

- 离线 Mock Provider 只用于契约和技术质量验证，不代表生产模型的语义或审美质量。
- 当前像素蒙版来自离线颜色/Alpha 连通域，可对受控异色相接/可见重叠对象提供颜色分离，并对同色可见中等宽接触轮廓提供形状分离候选；它不等同生产语义分割，也不会恢复被遮挡像素。改文字已能在 -90°～+90°范围对普通印刷体进行10°粗搜和1°精修，但精确竖排阅读方向仍需要用户选择；生产级中文 OCR、透视/弧形/艺术字检测、同色深度重叠或复杂遮挡对象分离、真实复杂毛发/玻璃/烟雾去背景、真实生图 Provider、隐私费用及内容策略验收仍是发布阻塞项。
- Windows 10/11 实机兼容、最终候选 PE/SBOM/校验和、三轮 1.1.3→2.0.0 安装升级生命周期、时间戳签名、多引擎扫描和许可证据未关闭前不得公开发布。

## 安全与隐私

看图和转图完全本地运行。任何联网 AI 图片上传与付费执行都必须逐次明确授权。公开候选包必须包含有效时间戳签名、SHA-256 清单、CycloneDX SBOM、第三方许可及可验证回滚包。
