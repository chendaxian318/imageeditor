## Delivered scope

- Theme selection supports light, dark and system-following modes. A single token set controls backgrounds, surfaces, foregrounds, muted text, borders, accents, focus and danger colours plus standard spacing.
- The process requests Windows Per-Monitor V2 DPI awareness before creating the root window. Tk scaling and monitor work area are refreshed as the window moves or resizes, and saved/dialog geometries are bounded to the active monitor.
- F6 and Shift+F6 move between viewing toolbar, editing toolbar, canvas, options panel and status area. Navigation/delete shortcuts preserve native behavior in text-entry controls.
- Canvas, toolbars, panel, status and interactive controls expose accessible names and keyboard focus. Menus use mnemonics and the shortcut reference is available with F1.
- First launch presents a dismissible guide. The empty state opens files by mouse or Enter; decode failures offer retry, choose another file and reveal-folder actions.
- Native Windows file drops are marshalled through a thread-safe queue. The Win32 window procedure never calls Tk directly, preventing the fatal GIL/thread-state exit reproduced in the previous implementation.
- `resources/locales/zh-CN.json` and `resources/locales/en-US.json` have matching stable keys. Language changes are applied to the running UI and persisted without reinstall or restart.
- Settings are grouped into appearance/language, performance/cache, saving/metadata, privacy, update and file-association pages.
- Core processing remains offline. There is no background upload, telemetry or automatic update request; `PRIVACY.md` is included in both the build release and installer.
