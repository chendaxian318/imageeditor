# v0.9.0-rc.1 发布说明

本版本进入功能冻结，只处理质量、性能、文档和发布问题。新增标准性能基线与 15% 回归门禁，覆盖启动、首图、切图、缩放、导出、批处理和工作集内存；新增 20,000 次浏览/1,000 项批处理长稳工具、异常注入、兼容矩阵、干净机生命周期、发布物本地 Defender/Authenticode 检查和提交到产物的可追溯证明。

预览管线会主动释放过期渲染结果和不再显示的中间像素，避免长时间切图、缩放或调整参数时依赖垃圾回收释放大型 PIL 缓冲区。

用户手册、隐私说明、第三方许可清单、SBOM、SHA-256、PyInstaller 诊断摘要与 RC 门禁状态随发布目录交付。

这是被门禁保护的候选构建，不是正式发行版。代码签名、第一方权属、至少 20 人 Beta、连续 7 天无新 P0/P1、Windows 10/11 干净 VM 和多引擎误报复核全部取得证据前，不得发布为 v1.0。
