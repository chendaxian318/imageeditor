# v0.4.0 acceptance record

Date: 2026-08-04  
Platform: Windows x64 / Python 3.12.10

## Scope delivered

- Serializable command timeline with fixed render stages and mergeable slider gestures.
- Stable undo, redo, branching and arbitrary history-node navigation.
- Fine rotation, automatic straighten, histogram, levels, RGB curves, temperature,
  tint, shadows, highlights, sharpening and denoise.
- Shared full-resolution renderer for preview, export, estimate and clipboard copy.
- Before/after split comparison and a visible history panel.
- Versioned `.lieproj` JSON project files with external source references, SHA-256
  checks, atomic save, schema migration and read-only future-command handling.
- Timeline-aware abnormal-exit recovery and Windows `.lieproj` registration.

## Automated gates

- Ruff format and lint: passed.
- Mypy: passed for application, installer, scripts and benchmarks.
- Unit/integration tests: 81 passed.
- UI smoke: asynchronous open, rotate, colour adjustment, fine rotation, preview
