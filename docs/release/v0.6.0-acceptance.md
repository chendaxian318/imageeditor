# v0.6.0 acceptance record

Date: 2026-08-04  
Platform: Windows x64, Python 3.12.10, Pillow 11.3.0

## Delivered scope

- AVIF decode/encode is enabled only after a runtime capability check succeeds.
- HEIF/HEIC registration is runtime optional through `requirements-heif.lock`; it is absent from `requirements.lock` and the default build.
- GIF, APNG and WebP sequences decode with bounded frame/memory limits, play in the viewer and export atomically as animations.
- Batch jobs persist a schema-versioned manifest after every state transition. A process interrupted during `running` reloads that task as `pending`.
- Queue concurrency is configurable from 1 to 16. A weighted semaphore prevents active image reservations from exceeding the configured memory budget.
- Recipes compose resize, watermark, metadata removal and format conversion. Presets use a versioned JSON representation and support import/export.
- Rename templates support `{name}`, `{stem}`, `{ext}`, `{index:04d}`, `{date}` and `{datetime}`. Unknown variables and empty/unsafe names fail validation.
- Same-directory inputs are detected, exact input/output identity is blocked unless explicitly enabled, and `error`, `overwrite` and concurrency-safe `unique` policies are available.
- Cancellation, failed-item retry, whole-job rerun, CSV/JSON logs, completion notification and output-folder actions are exposed in the Tk UI.

## Real UI smoke

- A real withdrawn Tk window opened a three-frame GIF through the background loader and advanced across multiple frames.
- The same window launched six AVIF conversion tasks through the UI queue; all six completed successfully.
- Worker progress crossed into Tk exclusively through a thread-safe queue polled by the main thread.

## Dependency decision

Pillow 11.3.0 already exposes a working AVIF codec on the locked Windows build, so no new base dependency was added. `pillow-heif==1.5.0` is available only in the optional lock. The default installer therefore has no HEIF native-code or licence expansion.

## Release constraints carried forward

- Public/commercial distribution remains blocked until upstream source rights are documented.
- Release signing still requires a publisher-controlled code-signing certificate.
- If `pillow-heif` is ever bundled, its complete native dependency licences must first be added to the shipped notice bundle.
