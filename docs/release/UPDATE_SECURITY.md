# 更新安全与回滚

轻量图片编辑器只在用户点击“立即检查更新”后联网。稳定版与测试版使用独立清单地址，但共享受信发布密钥集合。

客户端按以下顺序失败关闭：验证 RSA-SHA256 清单签名和通道；验证版本与 HTTPS 地址；下载到 `.part` 临时文件并限制声明大小；验证完整 SHA-256；验证 Windows Authenticode 状态为 `Valid` 且证书指纹在签名清单中；最后才把安装包原子加入本地更新缓存。任一步失败都会删除临时文件，且不会启动安装器。

每次成功缓存新版本时，上一个已完整验证的安装包会成为回滚候选。回滚仍由用户确认并通过正常安装升级流程退出主程序；缓存不是签名信任来源，安装包最初必须通过全部校验。

## 发布者操作

1. 使用受保护的 Windows 代码签名证书签署安装包并验证时间戳。
2. 用 `scripts/generate_update_manifest.py` 生成通道清单；清单中的 SHA-256、大小和 Authenticode 指纹必须来自最终安装包。
3. 私钥不得进入仓库、构建产物或 CI 日志；仓库只包含 `resources/update/trusted_keys.json` 公钥。
4. 发布清单与安装包后，从干净 Windows x64 环境分别测试稳定、Beta、断网、截断、篡改和回滚路径。

没有有效代码签名证书时可以生成本地测试构建，但不得发布到公开更新通道。
