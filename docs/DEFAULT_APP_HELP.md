# Windows 安装、卸载与默认图片应用帮助

## 安装

运行安装包。默认安装到 `D:\CSImage`，也可以在安装向导中点击“浏览”，通过图形化文件夹窗口选择其他本地目录。可选创建桌面快捷方式和“用 CSImage 查看”右键菜单。

## 设置为默认看图软件

1. 打开 Windows“设置 → 应用 → 默认应用”。
2. 搜索并选择“CSImage”。
3. 逐项选择希望交给本程序的 `.jpg`、`.jpeg`、`.png`、`.webp`、`.avif`、`.bmp`、`.tif`、`.tiff`、`.gif` 等扩展名。
4. 双击一张图片验证；连续双击多张时应只保留一个主进程。

安装器只注册候选能力并打开系统设置，不会绕过 Windows 或静默修改用户的默认应用选择。

## 升级与回滚

覆盖安装会通过本地 IPC 请求程序保存并正常退出。若用户取消退出，升级随即取消。正式发布页同时提供上一版本的签名回滚安装包；回滚前仍会复核清单签名、SHA-256 和 Authenticode 发布者。

## 卸载

从 Windows“已安装的应用”中选择“CSImage”并卸载。卸载程序会询问是否保留用户设置与缓存。静默卸载默认保留；维护人员显式使用 `/CLEARUSERDATA` 才会清除。

## 故障处理

- 未出现在默认应用列表：重新运行安装包完成覆盖安装，然后退出并重新打开系统设置。
- 双击仍由其他程序打开：在默认应用页面针对具体扩展名重新选择。
- 更新或回滚失败：不要绕过签名检查，导出诊断报告后提交至 <https://github.com/chendaxian318/imageeditor/issues>。
