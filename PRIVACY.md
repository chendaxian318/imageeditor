# Privacy / 隐私说明

Light Image Editor processes image pixels, metadata, projects, presets and batch jobs locally
on the user's Windows computer. Core viewing and editing features work without a network
connection.

轻量图片编辑器在用户自己的 Windows 电脑上处理图片像素、元数据、编辑项目、预设和批处理任务。看图与编辑核心功能在断网状态下仍可完整使用。

The application does not upload images in the background, perform telemetry, show ads, or
silently contact an update service. Version 0.7.0 checks for updates only when the user chooses
to obtain and install a newer package. Windows manages default-app associations and the user
must confirm any change in system settings.

本应用不会在后台上传图片，不进行遥测，不展示广告，也不会静默连接更新服务。v0.7.0 仅在用户主动获取并安装新版时更新。默认应用关联由 Windows 管理，任何变更均需用户在系统设置中确认。

Local settings, recent paths, recovery sessions and batch manifests remain in the current
user profile. Uninstall behavior and future diagnostic export features must keep deletion or
sharing under explicit user control.

本地设置、最近路径、恢复会话和批处理清单保存在当前用户配置目录中。卸载清理和未来的诊断导出功能必须继续由用户明确决定是否删除或分享。
